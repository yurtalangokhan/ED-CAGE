# ADR-0001: Use Continuous Architecture Governance

## Status

Accepted

## Context

Architecture governance decisions should be continuously evaluated using automated evidence rather than relying only on periodic manual reviews.

## Decision

The project will use ED-CAGE to evaluate architecture governance rules across repository, service, API, observability, deployment, security, reliability and dependency concerns.

## Consequences

Governance evidence will be generated continuously and reported through JSON, Markdown and evidence registry outputs.
